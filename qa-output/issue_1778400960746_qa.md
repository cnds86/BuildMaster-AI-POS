## Summary

พบ inconsistency ของ low-stock logic ระหว่าง `ProductGrid.tsx` (POS terminal) และ `InventoryList.tsx` (Inventory management) — fallback threshold ไม่ตรงกัน และ threshold ใน ProductCard ของ pos-ui ใช้ hardcode คนละค่ากับ ProductGrid

---

## Bug #1: ProductGrid.tsx — Wrong Fallback (minStock || 0)

**File:** `/home/cnds86/projects/MHX-POS/components/pos/ProductGrid.tsx`  
**Line:** ~133

```tsx
// Current (BUG)
const isLowStock = stock <= (product.minStock || 0);
```

**Problem:**  
- ถ้า `product.minStock` ไม่ได้ set (undefined) → fallback เป็น `0`  
- ทำให้ condition กลายเป็น `stock <= 0` → **only stock = 0** ถึงจะเข้า low-stock state  
- สินค้าที่ stock = 50 แต่ไม่มี minStock set → จะ **ไม่ถูก mark เป็น low-stock** แม้ว่าจริงๆ ไม่มี threshold ให้เปรียบเทียบเลย

**Expected:** ควร fallback เป็น `20` เหมือน InventoryList หรือใช้ค่า default ที่เหมาะสม

**Fix:** `const isLowStock = stock <= (product.minStock || 20);`

## Bug #2: ProductCard.tsx — Hardcoded Threshold (stock <= 5)

**File:** `/home/cnds86/repos/pos-ui/src/components/ProductCard.jsx`  
**Line:** ~22

```tsx
// Current (BUG)
{product.stock <= 5 && !outOfStock && (
  <span className="absolute top-2 right-2 bg-warning text-[#1e293b] text-xs font-medium px-2 py-0.5 rounded-full">
    ใกล้หมด
  </span>
)}
```

**Problem:**  
- Hardcoded `stock <= 5` → ไม่ได้ใช้ `minStock` threshold ที่ product กำหนด  
- ไม่ consistency กับ ProductGrid ที่ใช้ `minStock || 0`  
- ถ้า admin set `minStock = 50` แต่ stock อยู่ที่ 10 → **ไม่แสดง warning แม้จะต่ำกว่า minStock ที่กำหนด**

**Fix:** เปลี่ยนเป็นใช้ `product.minStock` threshold:  
```tsx
{product.stock <= (product.minStock || 20) && !outOfStock && product.stock > 0 && (
```

## Bug #3: InventoryList.tsx — Different Fallback (minStock || 20)

**File:** `/home/cnds86/projects/MHX-POS/components/inventory/InventoryList.tsx`  
**Lines:** 72, 158

```tsx
const isLowStock = product.stock < (product.minStock || 20);
```

**Problem:**  
- ใช้ fallback `20` ต่างจาก ProductGrid ที่ใช้ fallback `0`  
- ใช้ `<` (strictly less than) ต่างจาก ProductGrid ที่ใช้ `<=`  

**Impact:** สินค้าเดียวกันอาจถูก mark ต่างกันใน POS vs Inventory list

**File:** `/home/cnds86/projects/MHX-POS/components/pos/ProductGrid.tsx`
